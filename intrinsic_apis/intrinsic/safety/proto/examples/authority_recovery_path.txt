# Recovery path from EMERGENCY back to CONSTRAINED. Each step is
# <current mode> --<event>--> <next mode>. Emergency never clears straight to
# RECOMMEND or CONSTRAINED, and REVOKED returns to authority only via SHADOW.
AUTHORITY_MODE_EMERGENCY   --AUTHORITY_EVENT_CLEAR_EMERGENCY-->   AUTHORITY_MODE_REVOKED
AUTHORITY_MODE_REVOKED     --AUTHORITY_EVENT_RESET_TO_SHADOW-->    AUTHORITY_MODE_SHADOW
AUTHORITY_MODE_SHADOW      --AUTHORITY_EVENT_ARM_RECOMMEND-->      AUTHORITY_MODE_RECOMMEND
AUTHORITY_MODE_RECOMMEND   --AUTHORITY_EVENT_ENABLE_CONSTRAINED--> AUTHORITY_MODE_CONSTRAINED
